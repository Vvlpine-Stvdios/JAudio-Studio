    General Overview

    BMS (Binary Music Sequences) are MIDI-like sequenced audio file. They are entirely made up of assembly instructions as can be found below.

    Operation Codes

    BMS files use operation codes (or simply ‘OpCodes’) to tell the audio engine what to do. All opcodes are written in hexadecimal. Unnamed opcodes have not been found1.

    OpCode Name Format Description Example(s)
    0 NoOp OpC Does nothing. 00
    01–7F Note On OpC/Note, Voice, Velocity The OpCode is the note: 0x00 is C-1, 0x3C is C4, 0x7F is G9. Voice can be 1–7, Velocity can be 0–127. 46 01 7F, 3C 02 5E
    80 Wait OpC, Time Waits for time ticks. 80 1E, 80 3C, 80 78
    81–87 Note Off OpC/Voice Turns the note of the targeted voice off. The targeted voice is the opcode minus 80. 81, 82, 83, 84, 85, 86, 87
    88 Wait OpC, Time (2) 88 01 E0, 88 03 96
    89–97
    98 Set Param OpC, Target, Value Sets the target2 to the given value:
    1. Expression (?)
    2. Unknown
    3. Unknown
    		 98 00 53, 98 00 2D, 98 00 7F
    98 02 00, 98 02 19
    98 04 00
    99
    9A Set Pan OpC, ?, Value, ? Sets the pan to the given value, where 0x00 is Left (-64), 0x40 is Center (0), and 0x7F is Right (63). The first and third arguments seem solid at 0x03 and 0x0A. 0x03 is known to be the Pan target in v2, so it could simply be the case that this command is never used to set any other target. 9A 03 6E 0A, 9A 03 22 0A
    9B
    9C Set Param OpC, Target, Value (2) Sets the target2 to the given value:
    1. Volume; the high byte of the second argument appears to be the value, and the low is always double it.
    2. Pitch Bend; second argument is a signed 16-bit integer
    		 9C 00 68 D0, 9C 00 7D FA
    9C 01 FD 7A, 9C 01 FB 1E
    9D
    9E Set Param over Time OpC, Target, Value (2), Time Sets the target2 to the given value over the given length of time:
    1. Pitch Bend; second argument is a signed 16-bit integer
    		 9E 01 FB 80 04, 9E 01 00 00 04
    9F
    A0 Unknown OpC, ?, ? A0 00 01
    A1 Unknown OpC, ?, ? A1 00 05
    A2–A3
    A4 Program Change OpC, Target, Value Sets the target to the given value:
    1. Unknown
    2. Unknown
    3. Bank Select
    4. Program Select
    		 A4 01 00, A4 01 01
    A4 07 02, A4 07 0C
    A4 20 05
    A4 21 00, A4 21 01
    A5
    A6 Unknown OpC, ?, ? A6 04 0B
    A7 Unknown OpC, ?, ? A7 00 01
    A8–AB
    AC Unknown OpC, ?, ?, ? AC 00 00 00, AC 00 00 01, AC 00 00 02
    AD Unknown OpC, ?, ?, ? The final two arguments appear to potentially be a signed 16-bit boolean. AD 00 FF FF, AD 04 FF FF
    AE–C0
    C1 Track Pointer OpC, Track, Pointer (3) Defines a track n at the given location in the file. C1 09 00 34 33
    C2–C3
    C4 Call OpC, (?), Pointer (4) Calls a subroutine. Jumps execution to a new location in the file until a Return is hit. Sometimes, the second byte is C0. When that occurs, the 3 byte pointer is taken after it. I it unknown what this actually does, other than that it happens sometimes. C4 00 00 15 A0
    C4 C0 00 00 00 AD
    C5
    C6 Return OpC, ? Returns execution to where it left off. The argument could be a nop, but it shows up every time. C6 00
    C7
    C8 Jump OpC, ?, Pointer (3) Jumps execution back to a given location; is used to loop tracks. It is unknown what the first argument does. C8 00 00 00 27, C8 01 00 00 A0, C8 02 00 00 80
    C9–CA
    CB Unknown OpC, ?, ? CB 09 00, CB 0A 04
    CC Unknown OpC, ?, ? CC 09 00, CC 0A 00
    CE–D1
    D2 Unknown OpC, ? D2 29 00
    D3–D9
    DA Dynamic Track Label OpC, Track Used for string stabs?3 DA 05, DA 0E
    DB–DC
    DD Unknown OpC, ?, ?, ? The final two arguments appear to potentially be a signed 16-bit boolean. DD 00 FF FF
    DE–E5
    E6 Set Modulation OpC, Value (2) Sets the modulation to the given value. E6 00 00, E6 01 E0, E6 07 C0
    E7 Start Track OpC, ?, ? Always at the start of a track. The two arguments are always zero. These could just be nops, but they show up every time. E7 00 00
    E8–ED
    EE Unknown OpC, ?, ? EF DA 02 DA
    EF–F0
    F1 Unknown OpC, ? F1 40
    F2–F3
    F4 Unknown OpC, ? F4 3A
    F5–FC
    FD Set Tempo OpC, ?, Tempo The second argument sets the tempo in Beats per Minute. The first argument is always zero; unknown if it does anything. FD 00 55, FD 00 92
    FE Set PPQN OpC, ?, PPQN The second argument sets the PPQN (Parts per Quarter Note) in Ticks. Is always 12 FE 00 78
    FF End Track OpC Terminates a track. FF
